## 알려진 한계

- localStorage 용량 때문에 큰 사진 여러 개를 저장하면 용량 오류가 날 수 있습니다. 오류 시 기존 저장 자료와 화면 입력을 유지하고 크기를 줄이도록 안내합니다.
- 원본 이미지 EXIF 등 메타데이터를 제거하지 않습니다. 권리 메모·출처는 내보내기에서 제외되지만 원본 이미지 자체에 포함된 내용은 그대로 나갑니다.
- 로컬 저장소는 인증·암호화된 서버가 아닙니다. 상품 권리 확인과 검수자의 신원을 외부에서 검증하지 않습니다.
- JSON은 프로젝트 백업이나 공식 업로드 양식이 아닙니다. 원본 이미지 파일/ZIP/상세 이미지 패키지를 제공하는 다음 단계가 필요합니다.
- 화면의 기본 검수 완료는 채널의 모든 필수값을 충족했다는 뜻이 아닙니다. 실제 판매자센터 등록·노출·주문은 검증하지 않았습니다.
- 테스트는 합성 데이터만 사용했습니다. 실제 상품 5개 검증과 운영 성과 측정은 아직 수행하지 않았습니다.
- CI·배포는 구성하지 않았습니다. 커밋/Push 여부는 Git 원격 기록으로 확인합니다.
