# 가이드 모드와 실제 생성 검증 · 2026-11-10

이 폴더의 별 키링은 **imagegen으로 만든 가상 상품**입니다. 실제 모어비쥬 판매 상품이 아닙니다. 가격·옵션·배송 조건도 소프트웨어 검증용 설정이며 소재·크기·원산지는 입력하지 않았습니다. 실사용자 자료나 API 키는 포함하지 않았습니다.

## 실제로 진행한 경로

격리된 Chrome 브라우저에서 가이드 ON → 새 상품 → 이미지 파일 업로드 → 상품명·가격·옵션 입력 → 사진/판매 범위 및 테스트 권리 메모 저장 → OpenRouter GPT-6.1 Sol 실제 호출 → 제안 적용 → 초안 편집 → PNG 미리보기 → 테스트 검수·승인 → ZIP 다운로드를 수행했습니다. 브라우저 입력과 클릭을 사용했으며 모델 응답을 모의로 대체하지 않았습니다. 사용자의 기존 브라우저 상품은 변경하지 않았습니다.

- 실제 API 응답: HTTP 200, 약 **21.95초**. [원본 제안](proposal.json).
- 사진 관찰과 사실을 구분했고 소재·크기·원산지는 질문으로 남겼습니다.
- 앱이 필수 원장을 뒤에 덧붙여 중복이 생겼습니다. UI에서 그 중복 블록을 제거한 뒤 가격 4,500원, 1개, 민트 별 단일 옵션, 배송 3,300원/60,000원 이상 무료 조건과 테스트 표시를 다시 확인했습니다. [편집 후 문구](edited-draft.txt).
- 상세 PNG 2장을 시각 검수했습니다. 텍스트 잘림 없이 출력되고 원본 이미지 비율을 유지했습니다.
- ZIP을 다시 열어 원본 파일이 바이트 단위로 동일하고, 상세 PNG 2장도 미리보기와 동일함을 확인했습니다. 내부 권리 메모가 manifest에 없는 것도 확인했습니다. [검증 결과](export-check.json).
- 실제 판매자센터 등록은 수행하지 않았습니다.

## 솔직한 사용성 평가

개발 에이전트의 자체 사용 평가이며, 실제 판매자 대상 사용자 테스트나 측정된 생산성 수치가 아닙니다. **현재 7/10: 한 상품을 끝까지 만들 수 있지만, 매일 여러 상품을 올리는 완성형 도구로는 아직 손이 갑니다.**

좋아진 점:

- 가이드 ON/OFF가 입력 내용을 지우지 않습니다. 현재 필요한 영역을 강조하고, 각 작업 위치에 설명이 나타납니다. 단계는 저장된 상품 상태에 맞게 바뀝니다.
- 320/390/464/768/1024/1440px에서 편집 영역, 가이드, 버튼, 긴 안내문을 검사했습니다. 내보내기 버튼은 모바일에서 세로로 배치됩니다.
- 저장·생성 안내가 해당 폼 근처에 표시됩니다. 가이드와 완료 메시지를 읽으려고 매번 화면 위로 갈 필요가 줄었습니다.
- 필수 권리 메모가 필수로 표시되며, 누락 시 정확한 이유를 안내합니다. 이름 없는 상품은 삭제할 수 있고 삭제에는 확인이 필요합니다.

여전히 아쉬운 점:

- 하나의 긴 편집 화면이라 스크롤이 많습니다. 단계 이동과 현위치 안내로 줄였지만 단계별 마법사 수준으로 간단하지는 않습니다.
- 영역마다 저장해야 하고 미저장 상태에서 다른 폼을 잠급니다. 안전하지만 입력 흐름을 끊습니다. 자동 임시 저장은 아직 없습니다.
- AI 제안과 원장 조건이 반복될 수 있어 이번처럼 편집이 필요합니다. 사실 보존은 되지만 문구 완성도는 사람의 최종 정리를 전제로 합니다.
- 샘플 3종 불러오기는 반복 시 새 복사본을 추가합니다. 안내에 동작을 명시했지만 중복 확인 경험은 개선 여지가 있습니다.
- 계정 동기화, 자동 판매자센터 등록, 실제 검색 성과 측정은 없습니다. 실제 판매자 5상품 사용성 검증은 별도입니다.
