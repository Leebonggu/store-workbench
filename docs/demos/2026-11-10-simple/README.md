# 간단 만들기 실사용 검증 · 2026-11-10

사용자 피드백을 반영해 기본 화면을 **사진 → 짧은 질문 → 완성본**으로 변경했습니다. 기존 전체 편집과 가이드 모드는 상단 전체 편집 안에 남아 있습니다.

## 실제 테스트

앞선 시연에서 생성한 가상 민트 별 키링 이미지를 다시 업로드했습니다. 상품명·가상 가격 4,500원은 직접 입력하고, 판매 단위 1개·단일 디자인은 선택형으로 답했습니다. 소재·크기·원산지·배송은 모르는 상태로 두었습니다.

OpenRouter GPT-6.1 Sol에 실제 요청해 HTTP 200을 받았습니다. 응답·렌더링·확인·새로고침까지 약 21초였습니다. [실제 응답](generation.json)을 기록했습니다. AI는 모르는 소재·크기·원산지·배송을 확인 질문으로 남겼습니다.

완성본이 자동 적용되고 상세 PNG 미리보기가 바로 나타났습니다. 마지막 확인 체크 후 **이 내용으로 저장**을 눌렀고, 파일 다운로드 발생 횟수는 **0회**였습니다. 새로고침 후 확인 상태와 결과가 남는 것도 검증했습니다. 이 시연은 격리된 브라우저에서 실행했으며 사용자 기존 브라우저의 상품은 변경하지 않았습니다. 가상 상품은 실제 판매하지 않습니다.

## P0에서 달라진 점

- 한 번에 한 단계만 표시합니다. 원장·SKU·권리 메모 등 상세 편집 항목은 기본 화면에서 치웠습니다.
- 정해진 답은 선택형, 이름·가격·추가 설명은 직접 입력입니다. 모르는 선택형 항목은 모름을 고를 수 있습니다.
- 입력 정보와 사용 권한은 사용자가 명시적으로 확인합니다. 상세 출처를 항목마다 다시 입력하지 않아도 직접 입력·확인한 기록을 남깁니다.
- AI 제안을 따로 적용하는 과정 없이 생성한 결과를 바로 보여줍니다. 사진·가격·소재를 AI가 확인된 사실로 임의 확정하지 않습니다.
- 다운로드 없이 결과 확인·수정·저장이 가능합니다. 파일 내보내기는 접힌 보조 기능입니다.
- AI 요청이 실패해도 저장한 답변은 남습니다. 단, 새 유료 요청에 대한 동의는 다시 확인합니다.

사진만으로 가격이나 실제 판매 정책까지 알아내는 완전 자동 생성은 아닙니다. 필요한 정보는 여전히 판매자가 답해야 합니다. 초안 문구 중복과 실제 판매자센터 등록은 별도 검수·작업이 필요합니다. 사용성이 좋아졌다고 단정할 사용자 테스트 결과는 아직 없으며, 실제 사용자의 다음 피드백으로 판단해야 합니다.
