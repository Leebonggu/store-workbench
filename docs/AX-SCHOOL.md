# 노마드코더 AX School 챌린지 기록

기록일: 2026-11-04 (Asia/Seoul)

## 프로젝트 맥락

Store Workbench는 노마드코더 AX School 챌린지 과제로 진행하는 프로젝트다. 첫 과제는 Ideation & Planning이며, 이후 과제와 실제 사용 피드백에 따라 계속 확장하고 구현해 나간다. 첫 기획의 범위는 시작점이며 전체 제품의 영구적인 제한은 아니다.

## 확인한 클라이언트와 문제

- 실제 클라이언트는 사용자의 아내로, 오프라인 소품샵을 혼자 운영한다.
- 키링·캐릭터 상품·랜덤 가챠 등을 판매하고 스마트스토어도 운영한다.
- 가장 큰 문제는 매장을 운영하면서 온라인 상품까지 올릴 시간이 부족하다는 것이다.
- 상품 사진은 직접 촬영한다.
- 상품 상세 내용은 스마트스토어 내부 편집기로 작성·편집한다. 초기의 파워포인트 추정은 정정되었다.
- 상품 하나를 준비하는 데 약 1시간이 걸린다고 한다. 촬영·상세 제작·등록별 시간은 아직 구분해 측정하지 않았다.
- 보정을 많이 하는 편은 아니고, 본인이 느끼기에 결과물 품질도 만족스럽지 않다고 한다.
- 상품 관리와 저작권 관련 어려움도 있지만, 첫 우선순위는 상세 이미지·설명 제작 부담이다.
- 네이버에서 상호를 검색해도 원하는 가게를 찾기 어렵다는 문제도 있다. 세부 검색 영역과 원인은 미확인이며 SEO 문제로 확정하지 않는다.

공유 문구에서는 사용자의 수정 요청에 따라 첫 답변의 위치·상호 표현을 제거하고 **“오프라인 소품샵을 혼자 운영하는 제 아내를 위한 에이전트입니다.”**로 작성했다. 이 요청을 다른 모든 상호 표기의 삭제 요청으로 확대 해석하지 않는다.

## 첫 기획 범위

직접 촬영한 사진과 기본 상품 정보를 받아 누락 정보를 확인하고, 스마트스토어용 상세 이미지와 설명을 제작한다.

흐름: 사진·정보 제공 → 누락 확인 → 설명 작성·템플릿 배치 → 미리보기·수정·승인 → 이미지·문구 출력.

- 사람: 촬영, 상품 사실 및 사용 권한 확인, 결과 검수, 카테고리 선택과 최종 등록.
- 에이전트: 정보 정리, 추가 질문, 상세 설명과 이미지 초안 작성, 수정 반영.
- 원본 상품의 형태·색상을 보존하고, 미확인 상품 정보를 만들어 넣지 않는다.
- 법적 판매 가능 여부를 자동으로 판정하는 기능은 포함하지 않는다.
- 현재 로컬 템플릿 기반 기능과 앞으로 구현할 AI 기능을 구분한다. 실제 AI 호출·자동 등록·현장 검증이 완료되었다고 표현하지 않는다.

“초안만 받아도 도움이 될 것”은 사용자의 기획 가설이며, 아내의 확인된 사용 의향이 아니다. 완성도 높은 상세페이지가 한 번에 나오면 이상적이라는 의견도 사용자 의견이다.

## 검증과 확장 방향

실제 상품 5개로 기존 작업과 비교한다. 입력·검수·수정까지 포함한 직접 작업 시간, 수정 부담, 사실 정확성, 결과물 만족도, 실제 등록에 사용했는지를 확인한다. 최종 등록 시간은 별도로 기록한다.

아직 확인할 것:

- 단계별 기존 소요 시간과 실제 병목
- 아내의 초안 방식 사용 의향 및 실제 사용 피드백
- 지불 의향과 적정 금액
- 상품군별 필요한 정보와 사진·상품 권리 확인 방식

후속 후보는 카테고리 선택 지원, 실제 등록 자동화, 상품 관리, 네이버 검색 노출 개선이다. 자동으로 구현 범위에 포함하지 않고 후속 과제와 실사용 필요에 따라 결정한다. 상세 제작 개선이 검색 노출·매출 증가를 보장한다고 가정하지 않는다.
