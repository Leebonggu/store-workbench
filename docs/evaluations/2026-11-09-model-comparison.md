# 모어비쥬 한국어 초안 모델 비교 · 2026-11-09

결정: 기본 초안·사진 관찰 모델을 `openrouter/openai/gpt-6.1-sol`로 변경한다. GPT 한 모델이 사진 관찰 후보와 초안을 작성하며, 코드 검증과 판매자 승인을 거친다. 자동 다중 모델 합의나 사실 확정 기능은 구현하지 않는다. DeepSeek는 현재 기본 초안 모델로 선택하지 않는다.

## 방법과 한계

사용자 제공 상품 3종에 동일한 확인 사실·스타일·금지 규칙을 제공했다. 초안 품질을 분리 평가하기 위해 비교 호출에는 사진을 넣지 않았다. API는 OpenRouter chat completions, 출력 최대 3,000 토큰. 각 설정/상품당 1회씩이며 통계적 벤치마크가 아니다. 문구 평가는 개발 에이전트의 정성 검수이고 판매자의 블라인드 선호 평가가 아니다.

초기 4모델 × 3상품은 reasoning low로 호출했다. DeepSeek Pro는 이 설정/라우팅에서 요청 오류가 나 문구 비교에서 제외했다. DeepSeek Flash는 1개 응답이 추론 토큰 소진으로 잘렸다. 이 조건만으로 불리하게 평가하지 않도록 DeepSeek 두 모델은 reasoning disabled / 기본 라우팅으로 각각 3상품을 다시 비교했다. Pro의 별도 원인 확인 1회도 있었다.

핵심 기준: 가격·판매 단위·옵션·랜덤·중복·추가금·배송 보존, 미확인 정책/소재/크기/기능 창작 여부, 자연스러운 짧은 한국어, 질문과 공개 설명 분리. JSON 코드펜스 자체는 문구 품질의 탈락 사유로 삼지 않았다.

## 최종 비교 설정의 관측 비용·시간

| 모델 | 상품당 응답 시간 범위 | 3개 합계 API 보고 비용 |
|---|---|---|
| GPT-6.1 Sol | 5.9–6.5초 | $0.013222 |
| DeepSeek V4 Pro 0813 | 3.8–7.2초 | $0.006177 |
| DeepSeek V4.1 Flash 1017 | 4.0–4.8초 | $0.001035 |
| Gemini 2.5 Flash | 4.8–5.5초 | $0.007730 |

비용은 이번 응답의 `usage.cost` 합계이며 이미지 분석·Flue 반복 도구 호출 비용은 포함하지 않는다. 공급자 라우팅/캐시/토큰 수에 따라 변하며 앞으로의 고정 상품당 가격이 아니다.

## 발견한 사례

- **GPT-6.1 Sol:** 3종 모두 주요 가격·옵션·배송 조건을 보존했고, 검수에서 미확인 정책을 단정한 사례를 발견하지 못했다. 짧고 담백한 문구와 대괄호 소제목을 지켰다. 질문이 모두 최적이라는 뜻은 아니다. 응원 키링에 이미 공통 가격이 있는데 추가금 유무를 재질문하는 등 개선 여지가 있다.
- **DeepSeek V4 Pro / 추론 끔:** 빼빼로 상품의 배송 조건 누락. 태극기 상품에 “무작위나 중복 제공은 없어요”, 응원 상품에 “추가금 없이”를 추가했다. 입력에 없는 판매 정책이므로 승인 불가다.
- **DeepSeek V4.1 Flash / 추론 끔:** 빼빼로를 “키캡과 키링으로 두 가지로 즐길 수 있는” 상품으로 단정한 뒤, 질문에서는 실제로 둘 다 가능한지 묻는 모순. 태극기 상품 기본 가격 6,500원 누락. 응원 상품에 “옵션 추가금도 없습니다”를 추가했다.
- **DeepSeek Flash / 초기 low:** 태극기 상품에 “옵션 중복 선택은 되지 않습니다”를 추가했고 응원 상품 JSON이 잘렸다. 추론 끔 재검증으로 지연·잘림은 개선됐으나 사실 준수 문제는 남았다.
- **Gemini 2.5 Flash / 강화한 비교 프롬프트:** 주요 조건은 보존했다. 다만 빼빼로 키링의 에어팟 사용 등 미검증 적용 예시를 확장했고 질문이 장황한 경우가 있었다. 별도의 기존 Flue 사진 포함 실호출에서는 “현재 세트 할인은 제공되지 않으며”라는 미확인 정책을 생성했다. 후자는 프롬프트가 다르므로 동일 조건 비교 점수로 섞지 않고 운영 결함 사례로 기록한다.

## 적용

Flue/Pi 정적 카탈로그가 GPT-6.1 Sol 출시 전 버전이어서 `agent/src/model-provider.ts`에 공식 OpenRouter 메타데이터를 명시 등록했다. 검증된 기존 OpenRouter 프로토콜·인증을 유지하며 모델 ID/비용/문맥 정보를 추가한다. 출력 토큰 상한은 앱에서 8,192로 낮췄다. env로 다른 모델을 지정할 수 있으나 자동 대체하거나 동시에 비용을 발생시키지 않는다.

프롬프트도 함께 강화했다: 정보가 없음을 “없다”는 정책으로 바꾸지 않기, 사진 관찰은 observations에만, 미확인 값은 questions에만, FAQ는 알려진 사실로 답할 수 있는 것만, 일반 텍스트와 대괄호 소제목 사용.

참고: [GPT-6.1 Sol](https://openrouter.ai/openai/gpt-6.1-sol), [DeepSeek V4 Pro](https://openrouter.ai/deepseek/deepseek-v4-pro-0813), [DeepSeek V4.1 Flash](https://openrouter.ai/deepseek/deepseek-v4.1-flash-1017), [Gemini 2.5 Flash](https://openrouter.ai/google/gemini-2.5-flash). 실제 제공 모델·모달리티·가격은 같은 날짜의 OpenRouter `/api/v1/models`로도 확인했다.

## 실제 Flue + 사진 검증

선정 후 GPT-6.1 Sol로 상품 3종의 실제 사진을 전송했다. 앱 HTTP → Flue 상품 조회/제안 제출 도구 → 응답 검증 경로에서 모두 HTTP 200. 응답 시간은 15.0초, 14.8초, 15.0초. 검수에서 가격·랜덤·중복·선택 불가·추가금·배송 조건 보존과 사진 관찰 후보/미확인 질문 분리를 확인했다. 현재 확인된 세 사례의 결과이며, 이후 생성 결과의 정확성을 보장하지 않는다.

모델 비교 API 호출의 보고 비용 합계는 $0.03453284였다. 별도의 최초 Gemini Flue 호출 및 최종 GPT Flue 3회 비용은 이 비교 합계에 포함하지 않았다.
