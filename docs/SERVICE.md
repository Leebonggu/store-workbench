# 상품 작업대 서비스 소개

매장에 신상품은 도착했는데 사진 촬영, 상품 정보 입력, 상세페이지 제작이 밀려 온라인 등록을 미루는 소상공인을 위한 작업대입니다.

상품을 하나 고르면 지금 필요한 다음 행동이 보입니다. 직접 찍은 사진과 확인한 사실을 모으고, 빠진 정보와 권리 보류를 정리한 뒤, 문구와 상세 이미지를 만들어 검수합니다. 작업이 끝나면 판매자센터에서 사용할 원본 사진·상세 PNG·문구를 ZIP으로 받습니다.

## 일관되게 올리되 상품의 차이는 유지합니다

일관성의 대상은 정보 확인 수준, 사진 규격, 브랜드 말투, 검수 절차입니다. 상품의 색상·형태·옵션을 자동으로 바꾸지 않습니다. 원본 사진은 보존하고 상세 이미지에서는 사진 비율을 유지합니다. 생성된 문구도 판매자가 수정하고 승인합니다.

## 첫 버전의 범위

스마트스토어 수동 등록 준비에 초점을 맞춘 로컬 앱입니다. 계정이나 AI 키 없이 시작하며 사진·자료는 브라우저에 저장됩니다. 재사용할 수 있도록 촬영, 자산, 사실 검수, 권리, 문구, 상세, 승인, 채널 출력을 기능 블록으로 분리했습니다.

공식 판매처에 직접 게시하지 않습니다. 검색 표현 정리는 돕지만 노출이나 매출 증가를 보장하지 않습니다. 아직 실상품 운영 시험을 하지 않았으며, 현재 검증 자료는 모두 합성 예시입니다.

## 첫 사용에서 확인할 것

실제 미등록 상품 5개로 사진 준비, 정보 확인, 문구 수정, 등록 준비에 걸린 시간과 보류 사유를 기록합니다. 기존 방식과 비교한 뒤 개선 대상을 고릅니다. 온라인 유입·주문 변화는 이후 채널 데이터와 함께 별도로 확인합니다.
