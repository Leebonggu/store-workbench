QUICK START

사진, 짧은 답변, 완성본. 세 단계면 돼요.

  1. 새 사진으로 만들기 또는 사진 올리고 시작하기를 누르고 사진과 출처를 선택하세요.
  2. 상품명·가격을 적고 판매 단위와 디자인 선택 방식을 고르세요. 모르는 정보는 모름을 선택하거나 비워 두세요. 확인·사용 권한·전송 안내를 읽고 이 정보로 상세페이지 만들기를 누르세요.
  3. AI가 작성한 상세 이미지를 확인하세요. 필요하면 문구를 직접 수정할게요에서 다듬고, 확인 완료 · 이 내용으로 저장으로 마무리하세요.

다운로드는 필수가 아니에요. 결과가 이 브라우저에 저장되고 다시 열 수 있어요. 파일이 필요하면 결과 아래 파일로 다운로드하기 (선택)을 펼치세요. 스마트스토어에 자동 게시되지는 않습니다.

옵션별 가격·재고, 백업과 상세 설정은 상단 전체 편집에 있어요. 아래는 전체 편집 화면의 자세한 설명입니다. 그 화면에서는 가이드 모드 ON/OFF도 사용할 수 있어요.

STEP 01

상품을 만들고 사진 올리기

  1. 작업실 위쪽의 + 새 상품을 누르세요. 작성하지 않은 빈 상품이 있으면 그 상품을 다시 열어요.
  2. 상품의 첫인상, 사진에서 촬영·자료 출처를 적고 파일을 선택하세요.
  3. 원본 사진 추가를 눌러 저장하세요. 사진을 더 넣으려면 같은 과정을 반복해요.

사진 아래의 앞으로로 순서를 바꾸고, 제거로 사진 연결을 지울 수 있어요. 원본의 비율을 유지하며 제품을 새로 그리거나 자동 보정하지 않아요.

STEP 02

아는 정보만 확인하기

  1. 상품에 대해 알려주세요에 상품명·가격과 확인 근거를 입력하고 확인 완료를 체크하세요. 상품명과 가격은 초안 작성에 필요해요.
  2. 판매 단위, 옵션, 추가금, 배송 조건은 옵션 안내에 적고 확인 정보 저장을 누르세요. 옵션별 가격·재고·사진이 필요하면 아래 옵션 입력에서 저장하세요.
  3. 03 · 권리·판매 범위에서 사진별 사용 권한과 스마트스토어 판매·사용 범위를 체크하고 검토 메모·증빙 위치를 적은 뒤 권리 확인 저장을 누르세요.
예시 · 빼빼로 키캡 키링

판매 단위: 1개
12종 중 랜덤 1개. 디자인 선택 불가, 중복 가능.
배송비 3,300원 / 60,000원 이상 무료배송

크기를 모르면 추측해서 입력하지 마세요. 사진에 여러 개가 보여도 판매 단위가 자동으로 세트가 되는 것은 아니에요.

STEP 03

AI와 소개를 다듬기

  1. 우리 상품에 어울리는 소개를 함께.에서 원하는 방향을 적으세요.
  2. 사진·확인 정보·현재 초안의 외부 전송과 호출 비용 안내를 읽고 체크한 뒤 AI 제안 받기를 누르세요.
  3. 제안된 설명, 확인할 질문, 사진 관찰 후보, 검색어를 검토하세요. 새로 알게 된 사실은 상품 정보에 입력·확인한 다음 다시 요청하세요.
  4. 문구가 마음에 들면 제안을 편집 초안으로 적용을 누르세요.
이렇게 요청해 보세요

짧고 귀여운 말투로 써줘. 1개 가격이고 랜덤 발송이라는 점을 잘 보이게 해줘. 모르는 정보는 질문으로 남겨줘.

AI 문구는 제안이에요. 검색어와 FAQ가 검색 순위나 AI 검색 노출을 보장하지는 않아요. 키 연결이 안 되거나 호출이 실패하면 아래의 저장된 정보로 초안 만들기로 기본 문구를 만들 수 있어요.

STEP 04

미리 보고, 직접 확인하기

  1. 04 · 스마트스토어 초안에서 상품명과 상세 설명을 다듬고 초안 편집 저장을 누르세요.
  2. 사진/정보 출력 순서와 강조색을 고른 뒤 저장하고 상세 PNG 미리보기를 확인하세요.
  3. 가격·판매 단위·랜덤/선택 옵션·추가금·배송 조건이 맞는지, 사진과 문구가 제품을 정확히 설명하는지 확인하세요.

입력 영역을 바꿀 때는 먼저 저장해 주세요. 잘못 수정했다면 해당 영역의 입력 취소로 저장된 상태로 돌아갈 수 있어요.

STEP 05

승인하고 등록 자료 받기

  1. 마지막 확인, 그리고 내보내기의 미완료 항목을 먼저 해결하세요. 안내 아래 링크로 권한 확인이나 초안 준비 영역으로 이동할 수 있어요.
  2. 검수자 이름을 쓰고 사진·문구·옵션 확인을 체크한 뒤 현재 버전 승인을 누르세요.
  3. 사진·상세 이미지 ZIP 내보내기를 누르고 압축을 푸세요. 원본 사진, 860px 상세 이미지, 상품 문구와 목록 파일이 들어 있어요.
  4. 스마트스토어 판매자센터에서 자료를 사용해 직접 등록하세요. 카테고리·필수 고시·배송·반품·인증 등 판매자센터 요구 항목을 별도로 확인하세요.

내보내기 ≠ 실제 게시. 이 작업실은 스마트스토어에 자동 등록하거나 게시 상태를 조회하지 않아요. JSON은 등록 준비 데이터이며 판매자센터에 바로 올리는 양식이 아니에요.

KEEP IT TIDY

이름 없는 신상품 삭제하기

  1. 왼쪽 내 상품에서 삭제할 상품을 선택하세요.
  2. 선택한 상품 제목 옆의 상품 삭제를 누르세요.
  3. 확인 창에서 상품명을 확인하고 삭제를 확정하세요. 취소하면 그대로 남아요.

작업실의 사진·초안·확인 정보가 함께 삭제돼요. 복원이 필요할 수 있다면 페이지 아래 비공개 전체 백업을 먼저 받으세요. 스마트스토어에 이미 등록된 상품에는 영향을 주지 않아요.

여기서 막혔나요?

승인·내보내기 버튼을 누를 수 없어요.

바로 위에 표시된 미완료 항목을 확인하세요. 사진별 사용 권한, 스마트스토어 판매·사용 범위, 초안 준비가 필요해요. 승인 후 정보나 초안을 수정했다면 다시 검수·승인해야 해요.

다른 입력칸이 비활성화됐어요.

한 영역을 수정하는 동안에는 다른 영역의 입력을 잠가요. 현재 영역의 저장 버튼이나 입력 취소를 누른 뒤 이동해 주세요.

새 상품을 눌러도 같은 상품이 열려요.

내용 없는 상품이 계속 쌓이지 않도록 빈 상품을 다시 열어요. 이름 등 상품 정보를 입력하고 저장한 뒤 새 상품을 추가할 수 있어요.

다른 컴퓨터에서도 상품이 보이나요?

자료는 현재 브라우저에 저장되며 자동 동기화되지 않아요. 비공개 전체 백업을 내려받고 다른 기기의 백업 복원 도구에서 불러오세요. 복원 자료는 새 복사본으로 추가되며 승인은 다시 확인해야 해요.

AI 요청에 실패했어요.

기존 저장 초안은 유지돼요. 입력한 요청을 확인하고 다시 시도하세요. 연결 설정이 필요하다는 안내가 나오면 서버의 OpenRouter 키 설정을 확인해야 해요. 화면이나 상품 정보에 API 키를 입력하지 마세요.
